Add a reciter

Use this for reciters not in the built-in list — for example a beloved local reciter such as Sheikh Goni Tohir Dahiru. Either point to an audio source that follows a per-verse URL pattern, or record/upload verses yourself as you go using the 🎙️ button on each verse (stored privately in this browser).

Placeholders: {surah} {ayah} (plain numbers) or {surah3} {ayah3} (zero-padded to 3 digits, e.g. 001007).
Quran text & translation via AlQuran Cloud API. Built-in reciters via EveryAyah.com verse-by-verse audio. Not every reciter (including some cherished local reciters) has a public, per-verse audio API — use "Add a reciter" to plug in your own source or recordings.
